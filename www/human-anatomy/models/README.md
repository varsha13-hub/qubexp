# 3D Models for Human Anatomy VR

## Required Models

Place the following 3D models in this directory:

### skeleton.glb
- **Source**: Free from Sketchfab, TurboSquid, or other 3D model sites
- **Format**: GLB (GLTF Binary)
- **Requirements**: 
  - Human skeleton model
  - Optimized for web (under 10MB)
  - Properly rigged and textured
  - Compatible with A-Frame

## Recommended Sources

1. **Sketchfab** - Many free educational models
2. **TurboSquid** - Professional models (some free)
3. **CGTrader** - Community models
4. **Free3D** - Free models

## Model Guidelines

- Use GLB format for best performance
- Keep file size under 10MB
- Ensure proper scaling (human-sized)
- Test in A-Frame before use
- Include proper licensing information
